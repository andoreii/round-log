# Project rules

- Keep changes small and tied to the current milestone.
- Preserve the imported app's screens and interactions until the golf design pass.
- Prefer platform APIs and existing code. Add dependencies only when needed.
- Protect saved rounds, validate external input, and enforce account ownership.
- Keep tests focused on data loss, security, and changed behavior.
- Keep documentation short. Comments explain decisions the code cannot show.
- Use factual commit messages without co-author trailers or tool attribution.
- Keep secrets, personal data, generated output, and large files out of commits.
